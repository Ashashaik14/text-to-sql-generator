# Text-to-SQL Generator

A Flask-based web application that converts natural language queries into SQL queries using Google's Gemini AI.

## Features

- Convert text to SQL
- Supports:
  - SELECT
  - INSERT
  - UPDATE
  - DELETE
  - CREATE TABLE
  - JOIN
  - GROUP BY
  - ORDER BY
  - LIMIT
  - Aggregate Functions

## Technologies Used

- Python
- Flask
- Google Gemini API
- HTML/CSS
